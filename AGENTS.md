# Practicum Assistant

Автоматизация пользовательского интерфейса курса через TypeScript и Playwright.

- Node.js 22.18+, Chrome. Установка: `npm ci`. Проверка: `npm run check`, `npm test`.
- Сессия браузера, ответы, журнал и диагностические снимки локальные: `.local/`, `artifacts/`. Не публиковать их.
- Сначала исследовать фактический DOM через `npm run explore`. Не считать предполагаемые селекторы проверенными.
- Подтверждение прохождения — `course-navigation-lesson_status_solved` в меню, а не переход URL.
- Отправку ответа/проекта не повторять при тайм-ауте, пока не выяснено состояние предыдущей попытки.
- Эталоны проектов лежат в отдельном репозитории `solutions/`; привязывать их к полному SHA и проверкам.
- Не менять состояние прохождения прямыми запросами API, localStorage или подменой DOM.
- Не писать в поддержку, преподавателям или другим людям. Сдачи через внешние формы и документы оставлять локальными черновиками; о сбоях отчитываться пользователю со ссылками.
- Приёмку проекта отличать от прочтения урока сдачи, локальной самопроверки и проверки на имитации API.
- Сохранять исходную папку `.github/` при переносе эталонов; личные токены не включать в публичный код и сборки.
- PDF пользователя из корня не публиковать. Результаты сверки и ограничения чтения описывать отдельно.
