# Сбой официальной проверки «Закрывающий тег»

Проверено 19 октября 2026 года. Отчёт сохранён для пользователя. В поддержку не отправлялся; по решению пользователя внешние обращения не выполняются.

Официальная автопроверка проекта `zakrivayuschiy-teg-ad` завершается сообщением:
«Убедитесь, что страница не перезагружается при взаимодействии с кнопками: Сохранить на память, ОК».

Проверка: https://github.com/Alexey-UI/zakrivayuschiy-teg-ad/actions/runs/39209650578
Код проекта: `3fa7884a1b791718bf0fc2769790eba9668468b0`.

Причина воспроизведена отдельно от страницы проекта:

- В публичном тесте `modal()` используется `page.$x()`:
  https://github.com/Yandex-Practicum/tests-verstka-hometask-4-fd/blob/ad/src/tests.js#L279
- Общая библиотека тестов устанавливает Puppeteer `^22.15.0`:
  https://github.com/Yandex-Practicum/lib-verstka-tests-public/blob/main/package.json
- Метод `$x` удалён начиная с Puppeteer 22:
  https://github.com/puppeteer/puppeteer/releases/tag/puppeteer-core-v22.0.0

Минимальное воспроизведение на Puppeteer 22.15.0:

```js
const page = await browser.newPage();
console.log(typeof page.$x); // undefined
await page.$x('/html/body/*'); // TypeError: page.$x is not a function
```

Исключение перехватывается в `modal()` и заменяется общим сообщением о перезагрузке.
Падение происходит до клика по кнопке проекта. Оно не устраняется изменениями в разметке или скрипте диалога.

Локально точный XPath-сценарий с поддерживаемым API проходит. Дополнительно проверены
шесть ширин экрана, открытие и закрытие dialog без навигации, клавиатура и возврат фокуса.
Команда: `npm run check:closing` в репозитории
https://github.com/Alexey-UI/practicum-assistant.
GitHub Pages успешно собран: https://alexey-ui.github.io/zakrivayuschiy-teg-ad/.

Исправление на стороне владельцев тестов: обновить XPath-вызовы для используемой
версии Puppeteer либо закрепить совместимую зависимость.

Независимая проверка в интерфейсе Практикума приняла проект: показано
