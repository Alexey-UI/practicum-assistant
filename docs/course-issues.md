фактическое состояние интерфейса; причина сбоев загрузки не установлена.
Галочка чтения урока не подтверждает результат отдельного упражнения.

## Отправки с неизвестным результатом

- [Настройка ресурсов и сборки Vite](https://practicum.yandex.ru/trainer/ap-frontend-st/lesson/b8af3bf1-fb2b-45db-8c4e-a769604588a2/task/48562c28-a8e6-41db-ada5-a52ea03d75da/).
  После одной отправки результат не появился за пять минут. При повторном
  чтении сохранённый код доступен, уведомления о результате нет. Локальная
  сборка обеих HTML-точек входа прошла, приёмка тренажёром не подтверждена.
- [Последний шаг урока «Циклы»](https://practicum.yandex.ru/trainer/ap-frontend-st/lesson/32701e1c-1498-4813-b2c2-14e1bdca5301/task/bad35254-38e8-45df-97d0-a9645e0323a3/).
  Условие предлагает необязательную замену имени в `footer`. Сохранилась
  отправка без результата. При повторном чтении кнопки «Проверить» и
  «Следующий урок» доступны, уведомления о результате нет. Доступность
  перехода сама по себе не подтверждает принятие задания.
  Для нового запуска точный исходный шаг описан в `data/trainer-optional/`:
  программа оставляет имя автора примера и переходит дальше без отправки
  необязательной правки. Старая ожидающая отправка этим отказом не заменяется.
- [Шаг изучения структуры адаптивного проекта](https://practicum.yandex.ru/trainer/ap-frontend-st/lesson/0c8815a6-1908-496f-9af6-79ac1cc012d8/task/33745b64-4cc4-4907-b8f9-111fb0f2e6b7/).
  В истории осталась ранняя отправка без результата. Позднее в реальном
  интерфейсе подтверждён сценарий чтения без кнопки проверки. Для нового
  запуска он описан отдельным манифестом `data/trainer-demos/`; в число
  принятых автопроверкой заданий он не входит.

Встроенный пример HTML с `<h1>` независимо принят в отдельной анонимной
публичной песочнице; его решение включено в библиотеку. Исходная проверка
в аккаунте осталась без результата и сохраняется в `pendingInlineChecks`.

История неопределённых отправок сохраняется. Повторная отправка для
принудительного получения результата не выполняется.

## Проект «Закрывающий тег»

Работа принята Практикумом. Её официальный GitHub Action завершился ошибкой
совместимости тестов с Puppeteer; это отдельный результат проверки.
Подробности, ссылка на запуск и условия распознавания известной ошибки —
в [отчёте совместимости](official-checker-compatibility.md).

## Ограничения завершения курса

В текущем аккаунте остаются 13 опросов, требующих свободного отзыва или
не имеющих однозначного нейтрального ответа, четыре пустых задания,
одна сдача преподавателю и два закрытых урока. Это 20 уроков без отметки
прохождения. Сдачи преподавателю подготовлены локальными черновиками;
для реальной проверки API финального Mesto нужны личные параметры подключения.
