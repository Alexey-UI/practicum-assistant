# Запуск у себя

Для Windows, macOS и Linux. Нужны собственные аккаунты Практикума с доступом
к курсу `ap-frontend-st` и GitHub. Программа публикует проектные репозитории
открыто в аккаунте, выбранном при входе в GitHub CLI.

1. Установите [Node.js 24 с npm](https://nodejs.org/en/download),
   [Git](https://git-scm.com/downloads/), [Google Chrome](https://www.google.com/chrome/)
   и [GitHub CLI](https://cli.github.com/). Откройте новый терминал.
2. Выполняйте команды по одной строке:

   ```sh
   git clone --branch v0.3.0 https://github.com/Alexey-UI/practicum-assistant.git
   cd practicum-assistant
   npm ci
   gh auth login --hostname github.com --git-protocol https --web
   gh auth setup-git --hostname github.com
   npm run setup
   npm run login
   ```

3. В открывшемся Chrome войдите в свой Практикум. Дождитесь программы курса
   и нажмите Enter в терминале. Пароли и коды вводите только в браузере.
4. Для четырёх проектов с автопроверкой свяжите свой GitHub с Практикумом
   и создайте репозитории штатными кнопками на страницах сдачи проектов.
   Названия: `ono-tebe-nado-ad`, `posmotri-v-okno-ad`,
   `slozhno-sosredotochitsya-ad`, `zakrivayuschiy-teg-ad`.
   Репозитории для To-do и Mesto программа создаёт сама при необходимости.
5. Запустите:

   ```sh
   npm start
   ```

Чтобы пройти только до определённого модуля включительно:

```sh
npm start -- --until-course "Адаптивность"
```

Можно указать полное название либо уникальную часть. Обрабатываются модули
от начала программы до выбранного; ранее отмеченные уроки сохраняются.
Указанный предел нужно передавать при каждом повторном запуске. Без него
`npm start` обходит всю основную программу. Названия можно посмотреть через
`npm run status` после первого сбора каталога. При неоднозначном или неизвестном
названии программа остановится до прохождения уроков и покажет варианты.
`--until-course` нельзя совмещать с `--course` или `--url`.

Примеры ограничения по модулям («Введение» считается первым):

Только первый модуль:

```sh
npm start -- --until-course "Введение"
```

Первые два модуля:

```sh
npm start -- --until-course "HTML, CSS, JavaScript: вводный модуль"
```

Один конкретный модуль, без предыдущих:

```sh
npm start -- --course "Адаптивность"
```

Первые два примера выбирают все модули от начала до указанного включительно.
Последний выбирает только модуль, название которого содержит «Адаптивность».
Команды запуска подходят для версии v0.3.0 и новее.

Обновление с прежней версии из папки программы:

```sh
git fetch origin --tags
git switch --detach v0.3.0
npm ci
```

Сессия и результаты из `.local/` сохраняются. Полный каталог также сохраняется:
ограничение выбирает уроки для текущего обхода и его отчёта. Штатная кнопка
перехода за выбранную границу не нажимается. Неожиданный переход с загрузкой
страницы блокируется до запроса, а переход внутри SPA останавливает обход
при смене адреса. Неподтверждённый урок остаётся в отчёте.
`npm run status` по-прежнему показывает прогресс всей основной программы.

Обход работает в фоне. Не открывайте его служебный профиль Chrome параллельно.
Чтобы остановить, нажмите Ctrl+C и дождитесь сохранения. Чтобы продолжить,
снова выполните `npm start` из этой папки. Первая сборка каталога и работа
на медленной сети могут занимать заметное время.

Результаты: `npm run status` и файл `.local/run-report.md` в папке программы.
В отчёте будут ссылки и причины пропусков. Незнакомые упражнения и проверки
без ответа откладываются, обход продолжается. Повторной отправки зависшей
проверки нет. Для остановки на первом таком случае: `npm start -- --stop-on-pending`.
Ошибки авторизации, изменённые исходники или защитные проверки конфигурации
могут остановить запуск: прочитайте сообщение и не удаляйте историю проверок.

В Windows используйте `cmd.exe`; если PowerShell блокирует `npm.ps1`, пишите
`npm.cmd` вместо `npm`. На Linux для первого входа нужен рабочий стол;
поддерживаемые системы и архитектуры перечислены в [README](../README.md).

## Что остаётся без автоматического зачёта

- Недоступные задания после повторных загрузок и закрытые платформой уроки.
- Опросы, требующие свободного отзыва или не имеющие нейтрального варианта.
- Сдачи преподавателю: подготовлены проекты и черновики, отправка не выполняется.
- Mesto с API: код проверен на имитации сервера; для настоящего сервера нужны
  личные токен и группа. Их нельзя присылать в чат или публиковать в репозитории.
- Любое упражнение, для которого нет подтверждённого решения или результата проверки.

Подтверждены 577 заданий тренажёра и 375 встроенных упражнений; эти числа
описывают библиотеку, а не результат нового аккаунта. Повторный аудит
встроенных упражнений выполнен в 244 уроках. Полный запуск всего курса на
другом аккаунте ещё не подтверждён. Проверки кода на трёх ОС используют
тестовые страницы и не заменяют такую проверку. Обещания «все галочки
без исключений после одного запуска» у этой версии нет.

Известные случаи со ссылками: [проблемы курса](course-issues.md).
Дополнительные модули React и ИИ исключены; прежние результаты сохраняются.
Не переносите чужие `.local/`, `artifacts/`, cookies и токены.
