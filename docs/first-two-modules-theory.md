## 1. Введение: что делает разработчик и как учиться

**Фронтенд-разработчик** создаёт часть сайта, с которой взаимодействует пользователь
в браузере. Бэкенд обрабатывает запросы и данные на сервере. В первых двух модулях
задачи решаются на стороне браузера.

| Технология | За что отвечает | Пример |
| --- | --- | --- |
| HTML | Содержимое и его смысловая структура | Заголовок, текст, картинка, кнопка |
| CSS | Оформление и расположение | Размер, цвет, отступы, центрирование |
| JavaScript | Вычисления и поведение | Выбрать совет, отреагировать на клик |

В работе понадобятся редактор, файлы проекта, браузер и его инструменты разработчика.
Дизайнер определяет визуальное решение и взаимодействие; разработчик реализует его;
тестировщик проверяет поведение. Неясное требование сначала уточняют: что должно
произойти, при каком действии и какой результат считается правильным.

Рабочий учебный цикл: прочитать идею → написать небольшой пример → проверить
результат → объяснить своими словами → повторить без подсказки. Ошибку полезно
сократить до минимального примера. При обращении за помощью нужны код, ожидаемый
результат, фактический результат и точное сообщение об ошибке.

## 2. HTML: содержимое и структура

### Элементы, теги, атрибуты

```html
<p class="description">Описание страницы</p>
```

Элемент состоит из открывающего тега, содержимого и закрывающего тега.
`class="description"` — атрибут: имя и значение, указанные внутри открывающего тега.
У пустых элементов, например `img`, `meta`, `link`, закрывающего тега нет.

| Запись | Назначение |
| --- | --- |
| `<h1>…</h1>` — `<h6>…</h6>` | Заголовки по уровню вложенности и важности |
| `<p>…</p>` | Абзац |
| `<a href="…">…</a>` | Ссылка |
| `<img src="…" alt="…">` | Изображение и его текстовая альтернатива |
| `<div>…</div>` | Универсальный контейнер |
| `<span>…</span>` | Универсальная обёртка для части текста |
| `<header>`, `<main>`, `<section>`, `<footer>` | Шапка, основное содержимое, раздел, подвал |
| `<button type="button">…</button>` | Кнопка действия |

Уровень заголовка выбирают по структуре документа, размер задают CSS. Для обычной
страницы обычно достаточно одного основного `h1`. У тематической `section`
обычно есть собственный заголовок; для простой группировки подходит `div`.

**Вложенность:** элемент внутри другого — его потомок; непосредственно внутри —
его ребёнок. Внешний элемент — родитель. Пересекающиеся теги недопустимы:
правильно `<div><p>Текст</p></div>`, ошибочно `<div><p>Текст</div></p>`.

В обычном HTML-тексте несколько пробелов и переносов схлопываются. Расстояния между
элементами задают CSS. Символы разметки в тексте записывают как `&lt;`, `&gt;`, `&amp;`.
Комментарий: `<!-- пояснение -->`.

### Ссылки, изображения и пути

```html
<a href="https://example.com">Открыть сайт</a>
<a href="#contacts">К контактам</a>
<footer id="contacts">Контакты</footer>
<img src="images/cover.jpg" alt="Книга на деревянном столе">
```

- `href` — адрес ссылки, `src` — адрес ресурса. Их нельзя менять местами.
- `alt` передаёт смысл изображения при невозможности его увидеть; для чисто
  декоративной картинки используют `alt=""`.
- `images/cover.jpg` — путь от текущего HTML-файла; `../cover.jpg` — на уровень выше;
  `/images/cover.jpg` — от корня сайта; `https://…` — полный адрес.
- `id` должен быть уникальным в документе. Один класс может быть у многих элементов;
  одному элементу можно дать несколько классов: `class="card card-featured"`.

### Каркас документа и подключение файлов

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Название вкладки</title>
    <meta name="description" content="Краткое описание страницы">
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
  </head>
  <body>
    <h1>Заголовок на странице</h1>
  </body>
</html>
```

`doctype` включает стандартный режим отображения; `lang` задаёт язык; `head`
содержит метаданные и подключения; `body` — отображаемое содержимое. `charset`
указывает кодировку, `viewport` настраивает мобильное окно просмотра. `title`
и `h1` решают разные задачи: название вкладки и заголовок содержимого.

Для обычного внешнего скрипта `defer` откладывает выполнение до разбора HTML.
Другая базовая схема — подключить скрипт перед `</body>`.
Справка: [синтаксис HTML — MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax).

## 3. CSS: внешний вид и расположение

### Правило, селекторы, подключение

```css
.card {
  color: #222;
  background-color: #eef5ff;
  padding: 20px;
}
```

`.card` — селектор; внутри фигурных скобок — объявления `свойство: значение;`.
Комментарий в CSS: `/* пояснение */`.

| Селектор | Что выбирает |
| --- | --- |
| `p` | Все элементы `p` |
| `.card` | Элементы с классом `card` |
| `#contacts` | Элемент с `id="contacts"` |
| `*` | Все элементы |
| `h1, h2, p` | Несколько групп элементов |
| `.card p` | Абзацы внутри `.card`, на любой глубине |
| `.card.featured` | Элементы сразу с обоими классами |

CSS можно записать в атрибуте `style`, в `<style>` внутри `head` или в отдельном
файле, подключённом через `link`. Для проекта удобен отдельный файл.

**Каскад:** при конфликте учитываются источник и важность правил, затем
специфичность и порядок. Для обычных авторских правил без `!important` селектор
по `id` сильнее класса, класс сильнее тега; при одинаковой специфичности выигрывает
более позднее объявление. Это не означает, что любое последнее правило сильнее любого предыдущего.

**Наследование:** некоторые свойства передаются потомкам, например `color`,
`font-family`, `font-size`, `text-align`. `width`, `margin`, `padding`, `border`
обычно не наследуются. Собственное подходящее объявление у потомка заменяет
наследуемое значение. Фон обычно не наследуется: прозрачный потомок показывает фон родителя.

### Размеры и единицы

| Запись | Смысл |
| --- | --- |
| `width: 300px` | Ширина в CSS-пикселях |
| `width: 50%` | Обычно половина ширины содержащего блока |
| `height: 100vh` | Высота, равная высоте окна просмотра в единицах `vh` |
| `width: 50vw` | Половина ширины окна просмотра |
| `font-size: 100%` | Размер шрифта относительно размера шрифта родителя |

CSS-пиксель не обязательно равен одному физическому пикселю экрана. База процента
зависит от свойства: нельзя считать все проценты одинаково. `height: 100%`
обычно требует определённой высоты содержащего блока; это не замена `100vh`.
Блочный элемент с `width: auto` обычно занимает доступную ширину — лишнее
`width: 100vw` может создать горизонтальную прокрутку.

### Цвет, фон, прозрачность

```css
.hero {
  color: #fff;
  background-color: rgb(20 35 60);
  background-image: url("images/background.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

- Цвета: именованный `red`, шестнадцатеричный `#ff0000` / `#f00`, `rgb(255 0 0)`.
- В RGB три канала: красный, зелёный, синий; каждое целое значение от `0` до `255`.
  В шестизначном HEX им соответствуют пары `00`–`ff`: `#RRGGBB`.
- Альфа-канал: `rgb(0 0 0 / 0.4)` — цвет с непрозрачностью 40%.
- `opacity: 0.4` меняет непрозрачность всего элемента вместе с его потомками.
- `cover` заполняет область фона с возможным обрезанием картинки; `contain`
  показывает картинку целиком с возможными незаполненными областями. Пропорции сохраняются.
- `background-position` задаёт положение; `background-repeat` — повторение.
- Путь в `url(...)` отдельного CSS-файла отсчитывается от этого CSS-файла.

Смысловую картинку размещают через `img`, декоративную можно сделать фоном.
Для полупрозрачного слоя над фоном удобно вложить контейнер с цветом и альфа-каналом:
текст в нём останется непрозрачным.

### Текст и шрифты

| Свойство | Пример и назначение |
| --- | --- |
| `font-family` | `Arial, sans-serif` — шрифт и запасное семейство |
| `font-size` | `18px` — размер |
| `font-weight` | `400`, `700`, `normal`, `bold` — насыщенность |
| `font-style` | `italic` — курсив |
| `line-height` | `1.5` — высота строки в 1,5 размера шрифта элемента |
| `letter-spacing` | `1px` — дополнительный интервал между символами |
| `text-align` | `center` — выравнивание строчного содержимого внутри контейнера |
| `text-transform` | `uppercase` — отображение прописными буквами |
| `text-decoration` | `underline` / `none` — оформление линии под текстом |

Для названий шрифтов из нескольких слов используйте кавычки: `"Times New Roman"`.
Само указание названия не загружает шрифт: он должен быть доступен системе или
отдельно подключён. `text-align: center` не центрирует сам блочный контейнер.

### Поток, блочная модель и отступы

Обычный поток — исходный порядок расположения элементов. Блоки обычно идут
вертикально, строчное содержимое размещается в строках и переносится.
Вложенные блоки образуют вложенные коробки:

```text
margin → border → padding → content
внешний отступ → граница → внутренний отступ → содержимое
```

При `box-sizing: content-box` заданная ширина относится к содержимому:
`width: 200px; padding: 20px; border: 2px solid` дают внешнюю ширину коробки
`200 + 40 + 4 = 244px`, без учёта `margin`.
При `box-sizing: border-box` границы и внутренние отступы входят в заданные `200px`.
Внешние отступы не входят в `width` ни в одном из этих режимов.

```css
* {
  box-sizing: border-box;
}

body {
  margin: 0;
}

.card {
  width: 300px;
  padding: 20px;
  border: 1px solid #ccc;
  margin-bottom: 24px;
}
```

Браузер задаёт некоторым элементам исходные стили. Сбрасывайте нужные отступы
и размеры осознанно, перед собственными правилами. Соседние вертикальные
`margin` обычных блоков могут схлопываться; `padding` не схлопывается.
Подробности: [блочная модель — MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model).

**Краткая запись `margin` и `padding`:**

| Значения | Распределение |
| --- | --- |
| `10px` | Все четыре стороны |
| `10px 20px` | Верх/низ; лево/право |
| `10px 20px 30px` | Верх; лево/право; низ |
| `10px 20px 30px 40px` | Верх; право; низ; лево — по часовой стрелке |

Нулевую длину можно писать без единицы. Граница: `border: 1px solid #ccc` —
толщина, стиль, цвет. Отдельно существуют `border-width`, `border-style`, `border-color`.

### Display, центрирование, тени

| `display` | Поведение |
| --- | --- |
| `block` | Блочная коробка; обычно занимает отдельную строку |
| `inline` | Строчная коробка; обычные `width` и `height` её размер не задают |
| `inline-block` | Стоит в строке, но допускает ширину, высоту и отступы как коробка |
| `flex` | Делает непосредственных детей flex-элементами |

У `inline-block` пробельные символы HTML между соседями могут оставлять видимый зазор.

```css
/* Центрирование блока по горизонтали: нужна ширина меньше доступной. */
.content {
  width: 80%;
  margin: 0 auto;
}

/* Центрирование ребёнка по обеим осям при наличии свободного места. */
.hero {
  display: flex;
  min-height: 300px;
}

.hero-title {
  margin: auto;
}

.card {
  box-shadow: 0 4px 12px 0 rgb(0 0 0 / 0.15);
}
```

У тени коробки значения означают смещение X, смещение Y, размытие,
расширение и цвет. Отрицательные смещения направляют тень влево/вверх.
`text-shadow: 1px 1px 3px #888` рисует тень текста и не принимает параметр расширения.

## 4. JavaScript: данные и вычисления

### Консоль, выражения и переменные

Консоль браузера выполняет JavaScript и показывает сообщения/ошибки.
**Выражение** вычисляет значение: `2 + 3`. `console.log(...)` выводит значение
для наблюдения; сам по себе вывод не меняет текст страницы.
Регистр важен: `phrases` и `Phrases` — разные имена.

```js
let count = 2;
count = count + 1;
const title = 'Моя страница';
console.log(count); // 3
```

`let` допускает новое присваивание, `const` — нет. Присваивание `=` сначала
вычисляет правую часть, затем сохраняет результат слева. Поэтому `count = count + 1`
корректно. Имя переменной начинают с буквы, `_` или `$`; цифры допустимы дальше.
Обычно используют понятные английские имена в `camelCase`.

`const` не делает объект или массив неизменяемым: его содержимое менять можно,
нельзя присвоить этой переменной другой объект. `let` и `const` имеют область
видимости блока `{ ... }`; до объявления обращаться к ним нельзя.

### Основные виды значений

| Вид | Пример | Что важно |
| --- | --- | --- |
| Число | `12`, `3.5`, `-2` | В десятичной дроби точка |
| Строка | `'Привет'`, `"Привет"` | Кавычки должны составлять пару |
| Булево значение | `true`, `false` | Без кавычек |
| `undefined` | Результат функции без `return` | Значение не задано/не возвращено |
| `null` | Результат неудачного `querySelector` | Явное отсутствие значения/объекта |
| Объект | `{ name: 'Анна' }` | Набор свойств |
| Массив | `['чай', 'кофе']` | Упорядоченный объект со специальной работой индексов |

Проверка типа: `typeof 12` → `'number'`, `typeof '12'` → `'string'`.
Для массивов используют `Array.isArray(...)`: `typeof []` возвращает `'object'`.
Это необходимые на старте значения, а не полный список типов JavaScript.

### Арифметика и строки

```js
console.log(2 + 3 * 4);   // 14: умножение раньше сложения
console.log((2 + 3) * 4); // 20
console.log(7 % 3);       // 1: остаток от деления
console.log('Привет, ' + 'мир'); // конкатенация
console.log('Возраст: ' + 20);  // строка
console.log('2' + 3);     // '23'
console.log(2 + 3);       // 5
```

Операторы: `+`, `-`, `*`, `/`, `%`; скобки меняют порядок вычислений.
`+` складывает числа либо соединяет строки; смешение типов может дать неожиданный
результат. Для ясного преобразования подходят `Number('24')` и `String(24)`.
Непреобразуемая числовая строка даёт `NaN`. Длина строки: `'Привет'.length` → `6`.
Комментарии JavaScript: `// строка` и `/* несколько строк */`.

### Массивы и случайный выбор

```js
const phrases = ['Сделать разминку', 'Почитать книгу', 'Послушать музыку'];
console.log(phrases[0]); // первый элемент
console.log(phrases.length); // 3
console.log(phrases[phrases.length - 1]); // последний элемент

const index = Math.floor(Math.random() * phrases.length);
console.log(phrases[index]);
```

Индексы начинаются с `0`, последний индекс — `length - 1`. Обращение за пределы
обычного массива вернёт `undefined`. Элемент можно заменить: `phrases[0] = 'Отдохнуть'`.

`Math.random()` даёт число в диапазоне `[0, 1)`: ноль возможен, единица — нет.
Умножение на длину массива и `Math.floor` дают допустимый целый индекс.
`Math.floor` округляет вниз: `3.9` → `3`, `-1.2` → `-2`.
Для пустого массива случайного элемента нет: такой случай обрабатывают отдельно.

## 5. Функции, DOM и события

### Объявление, параметр, аргумент, return

```js
function getRandomElement(items) {
  const index = Math.floor(Math.random() * items.length);
  return items[index];
}

const phrases = ['Сделать разминку', 'Почитать книгу'];
const phrase = getRandomElement(phrases);
console.log(phrase);
```

- `function getRandomElement(...) { ... }` объявляет функцию. Её тело исполняется при вызове.
- **Параметр** `items` — локальное имя для входных данных в объявлении функции.
- **Аргумент** `phrases` — конкретное значение, передаваемое при вызове.
- Внутри функция обращается к `items`, поэтому работает с разными массивами.
- `return` передаёт результат вызывающему коду и немедленно завершает функцию.
- Функция без выполненного `return` возвращает `undefined`.

В учебной задаче с выводом можно написать `console.log(items[index])` внутри функции.
Это покажет элемент, но не вернёт его. Если нужно затем установить текст страницы,
удобен вариант с `return`. `getRandomElement` — ссылка на функцию,
`getRandomElement(phrases)` — её вызов. Без скобок вызова выполнения нет.
Справка: [функции — MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Functions).

### DOM: найти элемент и изменить его

DOM — объектное представление HTML-документа, доступное JavaScript.
Строка селектора в `querySelector` использует тот же базовый синтаксис, что CSS.

```js
const phraseElement = document.querySelector('.phrase');
const imageElement = document.querySelector('.picture');

phraseElement.textContent = 'Новая фраза';
phraseElement.style.fontSize = '24px';
imageElement.src = 'images/new-picture.jpg';
```

`querySelector` возвращает первый найденный элемент либо `null`. Если элемент
не найден, обращение к его свойствам вызовет ошибку: проверьте селектор и время
запуска скрипта. `textContent` заменяет текст; `innerHTML` разбирает строку как HTML,
поэтому для обычного текста предпочтителен `textContent`.

В `style` составное CSS-имя записывается в `camelCase`: `font-size` → `fontSize`,
`background-color` → `backgroundColor`. Числовая длина передаётся строкой с единицей:
`'24px'`. `classList.add('active')`, `remove('active')`, `toggle('active')`
добавляют, удаляют и переключают класс; в этих вызовах точку перед классом не ставят.

### Обработчик события

```js
const button = document.querySelector('.button');
const phraseElement = document.querySelector('.phrase');

button.addEventListener('click', function () {
  phraseElement.textContent = 'Кнопка нажата';
});
```

`addEventListener` связывает событие с функцией-обработчиком. Браузер вызовет её,
когда произойдёт клик. Именованную функцию передают без скобок:
`button.addEventListener('click', changePhrase)`. Запись `changePhrase()`
в этом месте немедленно вызовет функцию и передаст её результат вместо обработчика.

## 6. Условия, объекты, библиотеки и циклы

### Логика и условия

Сравнение возвращает `true` или `false`:
`>`, `<`, `>=`, `<=`, `===` (строгое равенство), `!==` (строгое неравенство).
`=` присваивает; `===` сравнивает. Например, `2 === '2'` → `false`.
`&&` — логическое «и», `||` — «или», `!` — отрицание.

```js
if (phrase.length > 40) {
  phraseElement.style.fontSize = '24px';
} else {
  phraseElement.style.fontSize = '32px';
}
```

Исполняется подходящая ветка. `else` нужен, если при следующем действии надо
вернуть обычный размер: прежний стиль сам не отменится. Несколько вариантов
записывают как `if (...) { ... } else if (...) { ... } else { ... }`.
В условии значения приводятся к логическому виду: `0`, `''`, `null`, `undefined`,
`NaN`, `false` дают ложь; обычные непустые строки — истину. Пустые массивы и объекты истинны.

### Объекты и методы

```js
const card = {
  text: 'Посмотреть на звёзды',
  image: 'images/stars.jpg'
};

console.log(card.text);
console.log(card['image']);
card.text = 'Посмотреть на облака';

const cards = [card, { text: 'Почитать', image: 'images/book.jpg' }];
const selectedCard = getRandomElement(cards);
phraseElement.textContent = selectedCard.text;
imageElement.src = selectedCard.image;
```

Объект связывает ключи со значениями. Точка подходит для заранее известного имени,
квадратные скобки — также для ключа из переменной. **Метод** — свойство, содержащее
функцию, например `console.log` или `Math.floor`. Элемент DOM тоже объект.
Присваивание объекта другой переменной не создаёт независимую копию:
обе переменные могут ссылаться на один объект.

### Внешние библиотеки

Библиотека — готовый код с интерфейсом использования. Сначала изучают документацию:
как подключить, что передать, что вернётся. В учебном проекте такой пример — Smoothly.
Общая схема для обычных внешних скриптов:

```html
<!-- library.js — полученный файл библиотеки; script.js — ваш код. -->
<script src="library.js" defer></script>
<script src="script.js" defer></script>
```

При такой схеме обычные скрипты с `defer` выполняются в порядке подключения.
Нельзя использовать API библиотеки до её загрузки. Если эффект не работает,
проверяют запрос файла во вкладке Network и ошибки в Console. Подключение
библиотеки само по себе не запускает нужный эффект: его вызывают согласно её API.

### Цикл for

```js
for (let i = 0; i < phrases.length; i = i + 1) {
  console.log(phrases[i]);
}
```

В круглых скобках: начальное значение → проверка условия перед повторением →
изменение счётчика после тела. `i++` — краткая запись увеличения на один.
Условие `< phrases.length` обходит допустимые индексы; `<=` добавит лишнее обращение.
Чтобы повторить действие трижды: `for (let i = 0; i < 3; i++) { ... }`.
Цикл без изменения условия может стать бесконечным и заблокировать страницу.
Обычный `for` не создаёт временных пауз между повторениями.

## 7. Пример: страница со случайным советом

Три файла положите в одну папку. Откройте `index.html` в браузере. Здесь используются
собственные примеры данных; внешние библиотеки и изображения не нужны.

**`index.html`:**

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Совет на перерыв</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
  </head>
  <body>
    <main class="card">
      <h1>Совет на перерыв</h1>
      <p class="phrase">Нажми на кнопку</p>
      <button class="button" type="button">Другой совет</button>
    </main>
  </body>
</html>
```

**`style.css`:**

```css
* {
  box-sizing: border-box;
}

body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  background-color: #edf3ff;
  color: #17233b;
  font-family: Arial, sans-serif;
}

.card {
  width: 90%;
  max-width: 500px;
  margin: auto;
  padding: 24px;
  background-color: #fff;
  border: 1px solid #ccd6e8;
  text-align: center;
  box-shadow: 0 4px 16px rgb(0 0 0 / 0.1);
}

.phrase {
  font-size: 32px;
  line-height: 1.4;
}

.button {
  padding: 12px 20px;
  font-size: 16px;
}
```

`max-width` ограничивает максимальную ширину карточки: она сохраняет боковое
пространство на узком экране и не растягивается чрезмерно на широком.

**`script.js`:**

```js
const cards = [
  { text: 'Сделать разминку' },
  { text: 'Почитать книгу' },
  { text: 'Отложить телефон и несколько минут посмотреть в окно' }
];

const phraseElement = document.querySelector('.phrase');
const button = document.querySelector('.button');

function getRandomElement(items) {
  const index = Math.floor(Math.random() * items.length);
  return items[index];
}

function changePhrase() {
  const card = getRandomElement(cards);
  phraseElement.textContent = card.text;

  if (card.text.length > 40) {
    phraseElement.style.fontSize = '24px';
  } else {
    phraseElement.style.fontSize = '32px';
  }
}

button.addEventListener('click', changePhrase);
changePhrase();
```

Связь частей: HTML создаёт элементы → CSS оформляет их → JavaScript находит
элементы → функция выбирает объект → обновляет текст и размер → событие повторяет
действие. Повтор того же совета допустим: случайный выбор не гарантирует новый результат.

## 8. Проверка себя и частые ошибки

| Симптом | Что проверить |
| --- | --- |
| Нет стилей | `href`, имя/регистр файла, сохранение файла, синтаксис CSS |
| Не видна картинка | `src`/`url`, относительный путь, имя и расширение |
| Размер блока неожиданно большой | `box-sizing`, `padding`, `border`, внешние отступы |
| Центрирование не работает | Что центрируется: текст или коробка; есть ли свободное место |
| Правило не применяется | Селектор, специфичность, порядок и наследование в DevTools |
| `ReferenceError` | Имя, область видимости, объявление переменной, загрузка библиотеки |
| Ошибка обращения к свойству `null` | Селектор и готовность DOM к моменту запуска |
| В результат попал `undefined` | Индекс, пустой массив, пропущенный `return` |
| Обработчик сработал сразу | Передали `changePhrase()` вместо `changePhrase` |
| Длинная фраза испортила все следующие | Есть ли ветка `else`, возвращающая обычный стиль |
| Страница зависла | Завершается ли цикл и меняется ли счётчик |

Умейте без подсказок:

1. Собрать HTML-документ, связать CSS и JS, объяснить атрибуты и вложенность.
2. Оформить текст, фон и карточку; рассчитать её размеры с учётом блочной модели.
3. Отличить `margin` от `padding`, `cover` от `contain`, наследование от каскада.
4. Выбрать случайный элемент массива и объяснить, почему последний индекс — `length - 1`.
5. Объяснить параметр и аргумент; показать разницу между `return` и `console.log`.
6. Найти элемент DOM, изменить его текст/свойство и назначить обработчик клика.
7. Написать условие, взять свойства случайного объекта и выполнить конечный цикл.
8. Проверить страницу на узком и широком окне, посмотреть Console и Network.

**Перед релизом:** сохранить файлы, перезагрузить страницу, проверить пути,
поведение кнопок и повторных действий, читаемость текста и отсутствие ошибок.
Релиз — подготовленная версия проекта, доступная пользователю; успешный тест
одного действия ещё не означает проверку всех сценариев.
