# Сопоставление проектов с PDF из СДО

Проверено 19 октября 2026 года. Исходные PDF остаются локальными и не публикуются.

| PDF | Репозиторий выполненной работы | Результат сверки |
| --- | --- | --- |
| КМ-П1. Оно тебе надо | [ono-tebe-nado-ad](https://github.com/Alexey-UI/ono-tebe-nado-ad) | Инструкция и чек-лист соответствуют материалам Практикума. Дополнительных условий в PDF не обнаружено. |
| КМ-П2. Посмотри в окно | [posmotri-v-okno-ad](https://github.com/Alexey-UI/posmotri-v-okno-ad) | Инструкция и чек-лист соответствуют материалам Практикума. Дополнительных условий в PDF не обнаружено. |
| КМ-П3. Сложно сосредоточиться | [slozhno-sosredotochitsya-ad](https://github.com/Alexey-UI/slozhno-sosredotochitsya-ad) | Инструкция и чек-лист соответствуют материалам Практикума. Дополнительных условий в PDF не обнаружено. |
| КМ-П4. Закрывающий тег | [zakrivayuschiy-teg-ad](https://github.com/Alexey-UI/zakrivayuschiy-teg-ad) | Полная сверка PDF невозможна: кириллица повреждена и в текстовом слое, и при отображении страниц. Обычное извлечение текста и локальный OCR не восстановили содержание. Работа проверена по исходному заданию Практикума. |

У первых трёх PDF сопоставлены инструкции и чек-листы с сохранёнными страницами курса.
Различия относятся к оформлению документа, колонтитулам и навигационным вставкам.
В частности, проверены ограничения лейаута «Посмотри в окно», переключение тем
и адаптивность «Сложно сосредоточиться», структура и геометрия «Оно тебе надо».

Повторные локальные проверки всех четырёх проектов прошли:

```sh
npm run check:ono
npm run check:window
npm run check:focus
npm run check:closing
```

Первые три работы прошли официальные GitHub Actions. Все четыре приняты в интерфейсе
Практикума, галочки уроков сдачи подтверждены. У четвёртой работы остаётся отдельный
[сбой официального GitHub-теста](official-checker-compatibility.md).

Это сопоставление требований и проверка кода. Документы в СДО, формы сдачи,
сообщения преподавателям и обращения в поддержку не отправлялись. Оценки и факт
сдачи в СДО не проверялись. Независимое измерение каждого пиксельного допуска
ревьюера и отдельная проверка в Firefox в эту сверку не входили.
